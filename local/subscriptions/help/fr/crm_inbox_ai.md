# Assistance IA de la CRM Inbox

L’assistance IA aide les administrateurs à comprendre et traiter les conversations du support.

## Fonctions disponibles

Elle peut proposer :

- la langue principale du message ;
- un niveau d’urgence ;
- une catégorie ;
- un résumé ;
- les demandes principales du client ;
- une suggestion de réponse ;
- une traduction ;
- une adaptation de ton.

## Validation humaine obligatoire

Les résultats IA sont des propositions.

L’IA ne peut pas :

- envoyer automatiquement une réponse ;
- accorder un accès ;
- confirmer un paiement ;
- rembourser un achat ;
- annuler une transaction ;
- suspendre un compte.

Une suggestion de réponse doit toujours être relue, corrigée et validée par un administrateur.

## Données CRM

Le contexte transmis à l’IA est limité aux informations utiles.

Les secrets, identifiants fournisseur, mots de passe, tokens et données bancaires ne sont jamais inclus.

## Confiance

Un score de confiance faible signifie que le résultat doit être interprété avec prudence.

Même avec une confiance élevée, le résultat ne constitue pas une décision métier.

## Quotas

Les analyses peuvent être limitées par :

- un quota global quotidien ;
- un quota quotidien par administrateur ;
- les limites du fournisseur IA.

## Fallback local

Le fallback local peut effectuer des analyses simples par mots-clés.

Il ne génère volontairement aucune réponse support complète.
