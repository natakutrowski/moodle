# Découvrir le CRM CampusFR

Le CRM CampusFR centralise les outils nécessaires au suivi des utilisateurs, des abonnements et des achats digitaux.

## Le Dashboard

Le Dashboard présente les informations importantes du moment :

- nouveaux utilisateurs ;
- nouveaux abonnements ;
- chiffre d’affaires digital ;
- profils à risque ;
- prospects chauds ;
- opportunités commerciales ;
- éléments à traiter.

Vous pouvez afficher les indicateurs pour aujourd’hui, la semaine en cours ou le mois en cours.

## Le Command Center

Le Command Center permet de rechercher rapidement :

- un utilisateur ;
- un abonnement ;
- un achat digital ;
- un produit ;
- une action administrative.

Utilisez `Ctrl + K` ou `Cmd + K` pour l’ouvrir.

## Les fiches utilisateur

Chaque fiche utilisateur rassemble :

- les informations personnelles ;
- les abonnements ;
- les achats ;
- les tags ;
- les notes ;
- la timeline ;
- les scores et recommandations CRM.

## Intelligence CRM

Le moteur Intelligence analyse les profils et détecte notamment :

- les prospects chauds ;
- les utilisateurs à risque ;
- les clients VIP ;
- les opportunités d’upgrade ;
- les utilisateurs inactifs.

> L’Intelligence CRM aide l’administrateur à prendre une décision. Elle ne remplace pas la validation humaine.
