# Gestion des Work Items

## Qu'est-ce qu'un Work Item ?

Les Work Items constituent le système de gestion du travail interne de CampusFR.

Ils permettent d'organiser :

- les demandes de support ;
- les incidents techniques ;
- les bugs ;
- les demandes de contenu ;
- les actions marketing ;
- les tâches administratives ;
- les suivis utilisateurs.

Chaque Work Item possède son propre cycle de vie et peut être relié à un utilisateur, un email, une automatisation ou tout autre objet du CRM.

---

# Différence entre Inbox et Work Items

L'Inbox représente les conversations.

Les Work Items représentent le travail à effectuer.

Une conversation peut ne produire aucun Work Item.

À l'inverse, plusieurs Work Items peuvent être créés à partir d'une même conversation.

---

# Cycle de vie

Les statuts disponibles sont :

- Ouvert
- En cours
- En attente
- Bloqué
- Résolu
- Fermé
- Annulé

Toutes les transitions sont enregistrées dans l'historique.

---

# Priorités

- Faible
- Normale
- Haute
- Urgente
- Critique

Les Work Items urgents apparaissent dans les tableaux de bord opérationnels.

---

# Équipes

Les Work Items peuvent être :

- assignés directement à un collaborateur ;
- assignés à une équipe.

Les équipes permettent de répartir automatiquement les responsabilités.

---

# Sous-tâches

Un Work Item peut contenir plusieurs sous-tâches.

Cela permet de décomposer une demande complexe en plusieurs actions indépendantes.

---

# Commentaires internes

Les commentaires sont visibles uniquement par les équipes internes.

Ils ne sont jamais envoyés au client.

---

# Liens CRM

Un Work Item peut être relié à :

- un utilisateur Moodle ;
- une conversation Inbox ;
- un contact ;
- un abonnement ;
- un paiement ;
- une règle d'automatisation ;
- une alerte Intelligence.

Ces liens facilitent la navigation dans le CRM.

---

# Bonnes pratiques

Privilégiez un Work Item par objectif métier.

Utilisez les commentaires internes pour documenter les décisions.

Fermez un Work Item uniquement lorsque toutes les actions sont terminées.
