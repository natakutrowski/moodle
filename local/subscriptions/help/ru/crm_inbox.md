# Работа с CRM Inbox

CRM Inbox централизует письма, полученные на `support@campusfr.fr`.

## Внешние контакты

Отправителю не обязательно иметь аккаунт CampusFR.

Разговор сохраняется с внешним контактом. Если человек позже создаст аккаунт с тем же адресом электронной почты, CRM сможет автоматически связать с ним предыдущую переписку.

Заблокированная ручная связь никогда не заменяется автоматически.

## Статусы

- **Открыто**: требуется действие.
- **В ожидании**: ожидается ответ контакта или третьей стороны.
- **Решено**: запрос обработан.
- **Закрыто**: разговор завершён.
- **Спам**: сообщение не является действительным обращением.

## Приоритеты

Используйте высокий и срочный приоритет только для запросов, требующих быстрой обработки.

## Назначение

Разговор можно назначить:

- администратору;
- команде;
- администратору, входящему в команду.

Связь с пользователем и административное назначение — разные понятия.

## Ответ

Можно сохранить черновик или отправить ответ непосредственно из CRM.

Ответы отправляются с адреса `support@campusfr.fr`.

## Вложения

Вложения копируются в Moodle File API и защищены правом просмотра Inbox.

## Архив и удаление

- **Локальное удаление**: скрывает разговор только в CRM.
- **Архив**: перемещает сообщение в папку архива провайдера.
- **Корзина**: перемещает сообщение в корзину провайдера.

Автоматическое окончательное удаление на сервере не выполняется.

## Диагностика

Страница диагностики проверяет:

- расширение PHP IMAP;
- учётные данные;
- соединение IMAP;
- соединение SMTP;
- таблицы;
- папки;
- ошибки синхронизации;
- ошибки загрузки вложений.
