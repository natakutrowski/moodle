# Поиск и горячие клавиши Command Center

**Command Center** дает администраторам быстрый доступ к страницам CRM, поиску пользователей, платежам, Inbox и Help Center.

Команды предоставляются внутренними providers.

## Открытие

Обычно используются:

```text
Ctrl + K
Cmd + K
```

Комбинация не должна мешать стандартным полям Moodle.

## Поиск

Введите часть названия команды.

Примеры:

```text
dashboard
users
payments
inbox
help
```

Могут поддерживаться алиасы и префиксы.

## Префикс Help Center

Запрос:

```text
> help
```

может показывать категории и статьи помощи.

Обычный запрос:

```text
help
```

также может возвращать статьи, если provider поддерживает поиск без префикса.

## Навигация клавиатурой

Рекомендуемое поведение:

- `Стрелка вниз`: следующий результат;
- `Стрелка вверх`: предыдущий результат;
- `Enter`: открыть;
- `Escape`: закрыть;
- `Tab`: доступная навигация;
- `Ctrl/Cmd + K`: переключить состояние.

Фокус должен быть видимым.

## Недавние команды

История может храниться в local storage браузера.

Кнопка очистки должна удалять только локальную историю.

После очистки стартовый экран обновляется сразу.

## Providers

Provider должен:

- принимать нормализованный запрос;
- возвращать структурированные результаты;
- проверять права;
- формировать безопасные URL;
- избегать тяжелых запросов;
- не возвращать произвольный небезопасный HTML.

## Команды пользователей

Можно открывать:

- CRM-профиль;
- User Explorer;
- переписку;
- недавние покупки;
- поиск по e-mail.

Все результаты должны учитывать capabilities.

## Команды помощи

Help provider должен использовать метаданные статей и Markdown-файлы активного языка.

CLI-валидатор должен сообщать об отсутствующих переводах.

## Безопасность

Command Center не повышает права.

Каждая целевая страница повторно проверяет:

- `require_login()`;
- `AdminSecurity`;
- Moodle capabilities;
- sesskey для изменений.

Скрытие команды не является защитой.

## Диагностика

Если команда не отображается:

1. очистите кэш;
2. проверьте регистрацию provider;
3. проверьте алиасы;
4. протестируйте поиск с префиксом и без;
5. проверьте capabilities;
6. изучите AJAX-ответ;
7. проверьте JavaScript;
8. убедитесь, что score результата больше нуля.

## Рекомендации

Используйте короткие и понятные названия:

```text
Открыть Dashboard CRM
Найти пользователя
Открыть цифровые покупки
Открыть CRM Inbox
Открыть Help Center
```
