# Управление рабочими элементами

## Что такое Work Item?

Work Item — это внутренний рабочий элемент CRM CampusFR.

Он используется для организации:

- обращений в поддержку;
- технических инцидентов;
- ошибок;
- создания контента;
- маркетинговых задач;
- административных задач;
- сопровождения студентов.

Каждый Work Item имеет собственный жизненный цикл и может быть связан с другими объектами CRM.

---

# Inbox и Work Items

Inbox хранит переписку.

Work Items описывают работу, которую необходимо выполнить.

Одно письмо может не создавать ни одного Work Item.

При необходимости из одной переписки можно создать несколько Work Items.

---

# Жизненный цикл

Доступные статусы:

- Открыт
- В работе
- В ожидании
- Заблокирован
- Решён
- Закрыт
- Отменён

Все изменения сохраняются в истории.

---

# Приоритеты

- Низкий
- Обычный
- Высокий
- Срочный
- Критический

Срочные Work Items отображаются на рабочих панелях.

---

# Команды

Work Item может быть назначен:

- конкретному сотруднику;
- целой команде.

Это позволяет эффективно распределять работу.

---

# Подзадачи

Work Item может содержать несколько подзадач.

Это удобно для крупных задач, которые необходимо разбить на этапы.

---

# Внутренние комментарии

Комментарии доступны только сотрудникам.

Они никогда не отправляются пользователям.

---

# Связи CRM

Work Item может быть связан с:

- пользователем Moodle;
- перепиской Inbox;
- контактом;
- подпиской;
- оплатой;
- правилом автоматизации;
- предупреждением Intelligence.

---

# Рекомендации

Создавайте один Work Item для одной бизнес-задачи.

Используйте внутренние комментарии для фиксации решений.

Закрывайте Work Item только после полного завершения всех действий.
