# Commerce 7.95F8C.2–F8E — Production Readiness

## F8C.2 — comparaison Legacy / Native

Le diagnostic reste strict sur les données métier. Les enrichissements Native ajoutés après migration sont ignorés uniquement sous `purchase.metadatajson` pour les préfixes suivants :

- `fulfillment_`
- `runtime_`
- `migration_`
- `audit_`

Une divergence sur le statut, le montant, la devise, les articles, les paiements, les fulfillments ou les droits reste bloquante.

## F8D — sauvegarde et rollback

```bash
php local/subscriptions/cli/commerce/audit_795f8d_backup_rollback.php \
  --database-backup=/srv/backups/moodle-db.sql.gz \
  --code-backup=/srv/backups/moodle-code.tar.gz \
  --moodledata-backup=/srv/backups/moodledata.tar.gz \
  --rollback-ref=commerce-7.94-rc1 \
  --max-age-hours=24 \
  --minimum-free-gb=5
```

L'audit est en lecture seule. Il vérifie la présence, la lisibilité, la taille et la fraîcheur des trois preuves de sauvegarde, l'espace disque, les outils de rollback et la résolution du point Git de retour.
