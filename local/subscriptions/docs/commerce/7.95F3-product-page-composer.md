# Commerce 7.95F3 — Product page composer

F3 separates the mandatory commercial shell from the editorial presentation of a product.

## Invariant

Every product page keeps the same server-generated price and purchase URL. A custom page cannot provide its own amount or checkout destination.

## Supported templates

- `default`
- `editorial`
- `immersive`

Unknown template identifiers fall back to `default`.

## Catalogue metadata

The preferred metadata shape is:

```json
{
  "storefront": {
    "template": "editorial",
    "theme": "a1-premium",
    "sections": [
      {
        "type": "rich_text",
        "title": "Une méthode complète",
        "content": "<p>...</p>"
      },
      {
        "type": "features",
        "items": [
          {"title": "Cours structurés", "content": "<p>...</p>"}
        ]
      },
      {
        "type": "faq",
        "items": [
          {"question": "Combien de temps ai-je accès ?", "answer": "<p>...</p>"}
        ]
      },
      {
        "type": "cta",
        "content": "<p>Prêt à commencer ?</p>"
      }
    ]
  }
}
```

Compatibility keys `storefront_template`, `storefront_theme`, and `storefront_sections` are also accepted.

## Supported section types

- `rich_text`
- `features`
- `media`
- `testimonial`
- `faq`
- `cta`
- `components`

Products with no explicit composition automatically render their long description and, for bundles, their components.
