# Commerce 7.95G7C–G7D — Promotion Cart Integration

## G7C — Calculation

- `CommerceCartCalculator` delegates promotion evaluation to an optional `CommercePromotionEngine`.
- Manual code is stored in cart metadata under `promotion_code`.
- Automatic promotions are loaded at every calculation.
- Percentage values use basis points; fixed amounts use minor currency units.
- Discounts are capped by the eligible subtotal and can never make the cart total negative.
- The snapshot exposes immutable, itemised promotion adjustments.
- Existing calculator construction remains compatible because the engine dependency is optional.

## G7D — Customer interface

- The cart summary provides real POST actions to apply, replace and remove one manual code.
- Invalid codes are evaluated server-side and returned as structured warning messages.
- Applied adjustments are displayed individually before the final total including tax.
- Customer strings are delivered in French, English and Russian.
- No checkout or redemption record is created in this phase; redemption is frozen later with the Purchase.
