# Commerce 7.95F6A — Merchandising Foundations

## Scope

F6A introduces the first conversion-oriented layer of the unified Native Storefront:

- curated marketing badges;
- active comparison prices and percentage discounts;
- featured products;
- deterministic manual display order.

## Metadata contract

No Legacy table is introduced. Configuration is stored in the Native product metadata:

```json
{
  "storefront": {
    "merchandising": {
      "featured": true,
      "displayorder": 10,
      "badges": ["new", "gustave_choice"],
      "promotions": {
        "EUR": {
          "compareamountminor": 19900,
          "start": 1785283200,
          "end": 1786147199
        }
      }
    }
  }
}
```

The active Native catalogue price remains the amount charged by checkout. The comparison price is display-only and is accepted only when it is strictly higher than the Native sale price and inside its optional validity window.

## Sorting contract

The public catalogue sorts products by:

1. featured status;
2. ascending `displayorder`;
3. translated product name;
4. SKU as deterministic final fallback.

## CRM editor

The existing **Page Boutique** step now exposes:

- featured product toggle;
- display order;
- curated translated badges;
- EUR and RUB comparison prices;
- optional start and end dates.
