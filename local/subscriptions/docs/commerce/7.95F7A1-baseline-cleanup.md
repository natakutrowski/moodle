# Commerce 7.95F7A.1 — Baseline cleanup

This corrective lot removes only fulfillment rows whose parent Native purchase no longer exists.

## Safety model

- Dry-run by default.
- Exact orphan IDs are displayed.
- Related purchase items, grants, digital accesses and fulfillment states are checked.
- Rows with detected dependencies are skipped by default.
- Execution requires an explicit confirmation token.
- No purchase, purchase item, grant, entitlement, Moodle enrolment or digital access is created or deleted.
- The operation is idempotent and relaunchable.

## Commands

```bash
php local/subscriptions/cli/commerce/cleanup_795f7a1_orphan_fulfillments.php
```

```bash
php local/subscriptions/cli/commerce/cleanup_795f7a1_orphan_fulfillments.php --json
```

After reviewing the dry-run:

```bash
php local/subscriptions/cli/commerce/cleanup_795f7a1_orphan_fulfillments.php \
  --execute \
  --confirm=DELETE-ORPHAN-FULFILLMENTS
```

Then rerun the F7A baseline audit.
