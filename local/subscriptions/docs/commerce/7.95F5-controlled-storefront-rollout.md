# Commerce 7.95F5 — Controlled Storefront rollout

F5 introduces an explicit, disabled-by-default rollout switch for the unified Storefront.

## Behaviour

When `local_subscriptions/storefront_enabled` is enabled, the historical course catalogue entry point redirects to `/boutique?type=course_access` while preserving the selected currency.

Compatibility is intentionally retained for:

- embedded historical catalogue displays;
- direct links carrying a historical `planid`;
- all existing checkout URLs.

The setting can therefore be enabled, observed and disabled without a database migration or destructive change.

## Regression included

The F4 test now uses the current Native product type constant `CommerceProductType::COURSE_ACCESS`. F5 also corrects the Storefront type filter value from the obsolete `subscription` token to `course_access`.
