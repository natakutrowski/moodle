# Commerce 7.95F8A–F8C — Production Readiness, batch 1

This batch is entirely read-only. It does not switch the Commerce runtime, migrate purchases, alter Git, or write business data.

## F8A — Git & Release Audit

```bash
php local/subscriptions/cli/commerce/audit_795f8a_git_release.php
```

Optional exact branch requirement:

```bash
php local/subscriptions/cli/commerce/audit_795f8a_git_release.php --branch=commerce-7.95
```

Blocking conditions include a dirty working tree, an unexpected branch, and a branch behind its upstream. Unpushed commits and a missing upstream are reported as important so they remain visible during DEV.

## F8B — Native Production Readiness

```bash
php local/subscriptions/cli/commerce/audit_795f8b_native_readiness.php --mode=native
```

The audit checks runtime/read configuration, checkout activation, rollback fallback, operational files, autoloadable Native classes, persistence/catalog tables, active products and prices, and orphan catalog mappings.

## F8C — Backfill Readiness

```bash
php local/subscriptions/cli/commerce/audit_795f8c_backfill_readiness.php --family=all --batch-size=100
```

The command reuses the existing Legacy source registry, snapshot factory, Native repository and comparator. It scans in bounded batches. Missing Native snapshots are classified as important because they represent expected work before the production backfill. Invalid Legacy records, divergent Native snapshots and orphan Native child rows are blocking.

## JSON output

Every command accepts `--json` and returns exit code `1` only when a blocking issue prevents certification.
