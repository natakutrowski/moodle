# Commerce 7.95F4 — Storefront CRM editor

F4 adds a dedicated CRM step for composing each product presentation page without editing JSON.

## Boundary

The editor can change only editorial metadata:

- page template;
- theme key;
- section order;
- titles and content;
- feature cards;
- media;
- testimonials;
- FAQs;
- CTA sections;
- bundle component placement.

Prices, currency resolution, purchase URLs, ownership and checkout remain controlled by Commerce.

## Storage

The editor persists the canonical `metadata.storefront` structure and removes deprecated flat Storefront keys. Every unrelated metadata key is preserved.

## Structured items

Feature and FAQ items use one line per item in the CRM:

```text
Title ||| Content
Question ||| Answer
```

This is converted server-side into the structured Storefront contract; administrators never manipulate JSON.
