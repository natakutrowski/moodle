# Commerce 7.95F7A — Baseline et matrice de certification

## Objet

F7A établit une photographie strictement en lecture seule de la boutique avant les certifications spécialisées F7B à F7H.

Le lot ne modifie ni le catalogue, ni les prix, ni les achats, ni les accès. Il ne contient aucune migration de base de données et ne nécessite aucun bump de version.

## Commande principale

```bash
php local/subscriptions/cli/commerce/audit_795f7a_storefront_baseline.php
```

Sortie JSON :

```bash
php local/subscriptions/cli/commerce/audit_795f7a_storefront_baseline.php --json
```

Rapport Markdown :

```bash
php local/subscriptions/cli/commerce/audit_795f7a_storefront_baseline.php \
  --output=/tmp/commerce-7.95F7A-baseline.md
```

Le script retourne `1` uniquement lorsqu'une anomalie bloquante est détectée. Une anomalie importante ou cosmétique reste visible dans le rapport sans rendre la baseline inutilisable.

## Périmètre inventorié

- produits Native par statut et type ;
- prix Native actifs, inactifs et par devise ;
- produits actifs sans prix actif ;
- traductions, composants, droits et mappings ;
- unicité des SKU ;
- unicité du mapping canonique Legacy → Native ;
- achats, lignes d'achat, fulfillments et grants ;
- plans, prix et produits numériques Legacy ;
- produits vedettes, badges et promotions ;
- promotions futures ou expirées encore configurées ;
- JSON de merchandising invalide ;
- relations orphelines.

## Classification

### Bloquant

Une anomalie qui empêche de considérer la boutique comme structurellement fiable : table absente, SKU dupliqué, prix orphelin, prix négatif, double prix actif, mapping canonique dupliqué ou achat orphelin.

### Important

Une incohérence qui doit être traitée dans une phase F7 spécialisée mais n'empêche pas l'inventaire : produit actif sans prix, fenêtre de disponibilité invalide, traduction orpheline ou JSON éditorial invalide.

### Cosmétique

Une anomalie de présentation sans conséquence sur le contrat commercial. F7A fournit la catégorie, même si le premier audit ne crée pas encore automatiquement ce type d'issue.

## Matrice de certification

| Domaine | Baseline F7A | Phase de certification |
|---|---:|---:|
| Catalogue et relations | Inventorié | F7A / F7E |
| Prix et promotions | Inventorié | F7B |
| Parcours d'achat | Volumétrie | F7C |
| Ownership et entitlements | Volumétrie | F7D |
| CRM, lifecycle et sécurité | Présence des structures | F7E |
| UX, responsive et multilingue | Métadonnées et traductions | F7F |
| Non-régression automatisée | Socle initial | F7G |
| Préparation PROD | Hors périmètre | F7H |

## Principe de sécurité

L'audit ne possède aucun mode de réparation. L'option `--output` écrit uniquement le rapport demandé sur le système de fichiers ; elle ne modifie jamais Moodle.
