# Commerce 7.95G4-G5 — Storefront cart UI

G4 connects the public storefront to the session cart through a POST-only, sesskey-protected action endpoint. G5 adds a responsive cart page rendered exclusively from `CommerceCartSnapshot`.

The delivery keeps checkout disabled until G6. Quantity controls are hidden for products whose catalogue policy fixes the maximum at one, while the domain remains capable of handling larger quantities.
