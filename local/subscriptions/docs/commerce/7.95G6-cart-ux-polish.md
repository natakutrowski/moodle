# Commerce 7.95G6 — Cart UX & Polish

This phase improves the customer-facing cart without changing the Cart domain or introducing checkout behavior.

## Decisions

- Product SKUs remain technical POST identifiers and are not displayed.
- Cart lines show the Storefront cover, product type and a details link opening in a new tab.
- Removal feedback uses the current `CommerceCartOperationResult::has_changed()` API.
- The customer summary displays TTC pricing and does not expose a separate tax row.
- Discounts are rendered only when they are non-zero; the promotion engine remains scheduled for G7.
- Payment reassurance is isolated in a reusable Native Commerce Mustache partial.
- New language strings are delivered in French, English and Russian.

No database migration or plugin version bump is required.
