# Commerce 7.95G7E — Promotion finalisation

- A manual promotion code is written to the session cart only after a successful server-side calculation.
- Rejected codes leave the cart and snapshot unchanged.
- Payment-provider icons are centered in the reusable reassurance component.
- Native CRM pages support listing, creating, editing, enabling, disabling and deleting promotions.
- Repository code lookups use an invalidated runtime cache.
- Administration input validates uniqueness, value, currency, limits and coherent dates.
