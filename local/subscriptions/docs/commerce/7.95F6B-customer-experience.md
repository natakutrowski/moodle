# Commerce 7.95F6B — Customer Experience

F6B adds four public Storefront capabilities without changing payment amounts or checkout routing.

## Grouped catalogue

Products are displayed in three stable groups: courses, resources and packs. The default group comes from the Native product type and can be overridden in Storefront metadata.

## Owned products

Ownership is resolved only from Native Commerce purchases for the connected user. Owned cards replace the purchase CTA with a safe access action. Course products point to Moodle courses; other products point to My purchases.

## Reassurance

The CRM editor controls secure payment, immediate access, CampusFR support and lifetime access labels. Defaults are derived from the Native product type.

## Quick facts

Up to six concise facts can be configured with one line per fact:

```
82 ||| vidéos
430 ||| exercices
35 ||| leçons
```

## Metadata contract

```json
{
  "storefront": {
    "experience": {
      "group": "courses",
      "trust": ["secure_payment", "immediate_access", "support", "lifetime_access"],
      "quickfacts": [
        {"value": "82", "label": "vidéos"}
      ]
    }
  }
}
```

No database migration and no plugin version bump are required.
