# Commerce 7.95G6.1 — UX stabilisation

This corrective batch stabilises the public Cart presenter API, keeps the Storefront F7 certification compatible with the Cart purchase action, and compacts the payment reassurance block.

## Guarantees

- `CommerceCartPresenter::present()` remains backward compatible with one argument.
- Storefront purchase-action certification accepts the historical quick-purchase URL or the Native Cart action.
- Immediate access is displayed before payment reassurance.
- FR, EN and RU labels are short enough to remain on one line in the cart summary.
- No database migration and no plugin version bump.
