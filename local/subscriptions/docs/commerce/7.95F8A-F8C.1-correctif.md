# Commerce 7.95F8A–F8C.1 — Correctif de readiness

## F8B.1

`db/install.xml` est la source de vérité du schéma. Les tables catalogue Native corrigées sont :

- `local_subs_commerce_prod_map`
- `local_subs_commerce_prod_ent`

L'auditeur utilise désormais ces noms exacts pour la présence des tables, le comptage des mappings et la détection des mappings orphelins.

## F8C.1

L'audit reste strictement en lecture seule et ajoute des diagnostics bornés :

- IDs Legacy manquants côté Native ;
- famille et ID Legacy du snapshot divergent ;
- ID, UUID et référence de l'achat Native ;
- chemins précis des champs divergents avec valeurs attendue/réelle ;
- détails des exceptions rencontrées sur les sources Legacy.

Limites de sécurité de sortie :

- 100 IDs manquants par famille ;
- 25 achats divergents ou invalides par famille ;
- 50 différences de champs par achat.
