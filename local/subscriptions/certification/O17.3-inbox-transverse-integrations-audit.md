# Commerce 7.95O17.3 — CRM Inbox transverse integrations certification

Base: Commerce 7.95O after O17.2.1 PHPUnit certification fixes.

## Scope

Static/coherence review of the CRM Inbox integration points outside the Inbox-only test corpus:

- CRM navigation and unread badge;
- `VIEW_INBOX` / `MANAGE_INBOX` capabilities;
- User Explorer / User360 Inbox exposure;
- Inbox → Work Item hand-off;
- scheduled tasks / cron integration;
- IMAP sync runtime, SMTP composition runtime and diagnostics storage checks.

## Findings

No new functional defect was identified during O17.3.

Confirmed invariants:

- Inbox capabilities are declared and consumed by navigation/user pages.
- CRM navigation keeps Inbox overview, compose, drafts and templates shortcuts.
- CRM navigation unread badge remains wired to `InboxUnreadCountService`.
- User Explorer removes Inbox-specific criteria/data when the viewer lacks Inbox capability.
- Inbox thread actions create Work Items with `WorkItemSource::INBOX`.
- The six Inbox scheduled tasks declared in `db/tasks.php` all have implementation classes.
- Sync remains wired through `InboxSyncRuntimeFactory`.
- Compose remains wired to SMTP + configured Inbox credential storage.
- Diagnostics covers Inbox account and template storage among its structural checks.

PASS pending execution of the localized PHPUnit certification guard on Moodle DEV.
