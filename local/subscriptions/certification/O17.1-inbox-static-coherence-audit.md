# Commerce 7.95O17.1 — CRM Inbox static/coherence audit

## Conclusion

O17.1 is **PASS after two localized corrective changes**. The CRM Inbox implementation is statically coherent enough to proceed to the full PHPUnit certification campaign in O17.2.

## Audited base

- Source archive: `subscriptions(20260822-103053).zip`
- Scope: CRM Inbox changes O1 through O16.3.7
- No database or upgrade change was required by O17.1.

## Static checks completed

- 248 Inbox-related PHP files linted with PHP 8.4 syntax: **0 failures**.
- Inbox AMD source/build JavaScript syntax checked: **OK**.
- No use of the invalid Moodle API `html_writer::section()` found in the Inbox scope.
- No residual `TODO`, `FIXME`, `var_dump`, `print_r`, `dd()` or `console.log()` found in the audited Inbox implementation.
- All statically detectable `get_string(..., 'local_subscriptions')` references in Inbox/admin/navigation resolve in EN, FR and RU after the O17.1 correction: **385 referenced strings, 0 missing strings per language**.
- O16.3 regression markers remain present: custom date range, filter icons, CSS breadcrumb/filter chevrons, last-sync display, internal Inbox/Drafts counters, recipient picker/autosave runtime markers.

## Corrective finding 1 — missing subject fallback translation

`admin/inbox/reply.php` uses `crm_inbox_thread_without_subject` when a thread has no subject, but this key was absent from EN/FR/RU language packs.

Correction: the key is now defined in all three supported languages.

## Corrective finding 2 — diagnostics did not cover O9 template storage

`InboxDiagnosticsService` validates the Inbox structural tables but omitted `local_subscriptions_inbox_template`, which stores signatures and quick replies introduced in O9.

Correction: `local_subscriptions_inbox_template` is now part of the structural diagnostics table list.

This means diagnostics can no longer report structural coherence while the O9 template table is missing.

## Certification guard added

`commerce_795o17_1_static_coherence_certification_test.php` guards:

- the translated no-subject fallback in EN/FR/RU;
- the presence of the O9 template table in Inbox diagnostics;
- the absence of `html_writer::section()` in the Inbox PHP scope.

## O17.1 decision

**PASS** — proceed to O17.2 full PHPUnit Inbox certification campaign after applying the O17.1 delta and running its localized test.
