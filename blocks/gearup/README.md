Level Up Quest
==============

Quest is a plugin to add gamification to a Moodle site.

Installation
------------

Place all the files in the folder `blocks/gearup` of your Moodle installation.

Activation
----------

A licence key is required to use the plugin. Please contact [support](https://levelup.plus)
to get or recover your licence.
